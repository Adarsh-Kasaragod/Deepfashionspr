# DeepFashion2 Dataset

DeepFashion2 is a large-scale, comprehensive dataset designed for advanced clothing analysis tasks such as detection, pose estimation, segmentation, and re-identification. 

## Overview
Unlike standard datasets, DeepFashion2 offers high diversity by featuring over 491,000 images covering 13 popular clothing categories. These images are sourced from both commercial shopping stores and everyday consumer photos, providing a robust mix of professional and real-world data.

## Key Features
- **Extensive Annotations:** Includes 801,000 clothing items labeled with scale, occlusion, zoom-in, viewpoint, category, and style.
- **Detailed Ground Truth:** Every item is annotated with precise bounding boxes, dense landmarks, and per-pixel masks.
- **Cross-Domain Matching:** Features 873,000 commercial-consumer clothing pairs, making it highly suitable for retrieval and re-identification tasks.

## Use Cases
Researchers and developers can leverage this dataset to build models for clothes detection, landmark and pose estimation, instance segmentation, and consumer-to-shop clothes retrieval.
Additionally, the system allows users to upload their own images to test real-world detection and analysis capabilities.

For full details, please refer to the official DeepFashion2 paper (CVPR 2019).
